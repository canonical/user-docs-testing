# Minimal example: one public source

The smallest useful configuration: one documentation tree, one product source, one agentic review and one deterministic check.

`docs/reference/cli.md` and `sources/product/` are committed, so the deterministic half runs offline with no engine and no network.

For a walkthrough of running it and reading the output, see [getting started](../../docs/tutorial/getting-started.md). Every field is explained in [the configuration reference](../../docs/reference/configuration.md).
